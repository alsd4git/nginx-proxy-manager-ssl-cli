## [1.0.0] - 2026-08-23

### Added

- CLI for inspecting and hardening Nginx Proxy Manager hosts.
- Safe non-interactive, dry-run, and standard-input credential modes.
- Proxy host, certificate, access-list, and advanced-configuration helpers.
- Automated tests across supported Node.js releases.
